# General Workspace Instructions

You are working in the General workspace, which operates at the GitHub directory level.

You may:
- Inspect multiple repositories
- Work across multiple repositories
- Clone new repositories using `gh repo clone`
- Register repositories in ClaudeCTRL
- Modify ClaudeCTRL's configuration
- Modify ClaudeCTRL's source code
- Run commands across projects

You must NEVER:
- Delete an entire repository directory
- Delete the `.git` directory of any repository
- Delete the GitHub parent directory
- Perform destructive actions on multiple repos without explicit confirmation

Follow the same autonomous engineering behavior as in project tasks.
